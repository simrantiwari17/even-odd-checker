# Even Odd Checker

## Description
A simple web app that checks whether a given number is even or odd using JavaScript.

## Features
- Takes number input from user
- Validates empty input
- Displays result dynamically
- Visual error feedback

## Technologies Used
- HTML
- CSS
- JavaScript

## Concepts Learned
- Modulus operator
- Event handling
- DOM manipulation
- Input validation
